# 🐰💜 ASCII Video Art – Jungkook Edition

**Turning video frames into art using nothing but text and symbols.**

A creative Python project that transforms video frames into ASCII art, creating a moving visual made entirely of characters.

## ✨ About the Project

This project combines programming with creativity to explore a different way of displaying videos.

Inspired by a Jungkook edit 💜, the program converts visual frames into text-based artwork, replacing ordinary pixels with letters and symbols.

The idea is simple: instead of watching a video made of pixels, watch it come to life through ASCII characters!

## 🎬 How It Works

The process involves a few simple steps:

1. **Video Processing:** The video is read frame by frame.
2. **Grayscale Conversion:** Each frame is converted into shades of gray.
3. **ASCII Conversion:** Pixel brightness is mapped to different characters and symbols.
4. **Frame Generation:** The characters are arranged to recreate the original visual.
5. **Playback:** The converted frames create an ASCII-style video.

## 🛠️ Technologies Used

- **Python** – Main programming language.
- **ASCII Characters** – Used to recreate visual details.
- **Video/Image Processing Libraries** – Used for processing frames and generating the output.
